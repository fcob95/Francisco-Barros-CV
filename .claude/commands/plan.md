description: Diseña un plan de implementación para la tarea descrita usando el subagente planner (read-only).
argument-hint: <descripción de la tarea o fase>
---

Invoca el subagente `planner` para diseñar un plan de implementación de: $ARGUMENTS

El plan debe alinearse con `PLAN.md`, `ARCHITECTURE.md` y las decisiones activas de `PROGRESS.md`.
Incluye: pasos ordenados, archivos a tocar, funciones/utilidades existentes a reutilizar (con ruta),
criterios de aceptación y riesgos. No escribas código todavía: solo el plan. Si hay un gap o ambigüedad
que cambie el enfoque, márcalo para escalar.
